- **Administrator** manages settings, credentials, profiles, agents, and all resources.
- **Editor** creates applications, monitors, ELF queries, and suites but cannot read credentials.
- **Operator** runs, cancels, probes, tests, acknowledges, and inspects sanitized evidence.
- **Viewer** reads definitions and sanitized results.

Authorization is enforced by the API. Hiding an action in the interface is not a security boundary.
