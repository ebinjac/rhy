Certificate profiles support trust bundles and client identity material. Upload the source file, choose its purpose, provide a password through a secret reference when required, and inspect the parsed certificate chain before saving.

Supported inputs include PEM, CRT/CER, DER, PKCS#12/PFX, and JKS. Rhythm records safe metadata such as subject, issuer, validity, fingerprints, key usage, and chain order without returning private keys.

<SecurityNote>Passwords must use secret references. Private-key material is encrypted at rest and never appears in API responses, diagnostics, copy actions, or documentation.</SecurityNote>
