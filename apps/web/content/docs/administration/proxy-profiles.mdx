A proxy profile defines scheme, host, port, authentication reference, optional TLS profile, and ordered no-proxy rules.

Use **Test connection** with an allowed destination before linking the profile to a monitor or ELF connection. The result explains DNS, proxy connection, TLS, and policy decisions without exposing credentials.

No-proxy decisions are recorded in run diagnostics so operators can distinguish direct and proxied routes.
