## Error envelope

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "The request could not be validated.",
    "details": {}
  },
  "meta": { "requestId": "req_example" }
}
```

Use `error.code` for program logic and retain `meta.requestId` for support. Messages are safe for display but may change for clarity.

## Pagination

Pass the opaque `meta.page.nextCursor` to the next request. Never parse, increment, or persist assumptions about cursor structure.

## Asynchronous work

Manual monitor runs and deployment validations return `202 Accepted` with an ID. Poll the corresponding detail endpoint until a terminal status, or cancel through its explicit cancel operation.
