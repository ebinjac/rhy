Rhythm's application UI and `/api/v1` API are currently available without user
authentication. Every request uses the shared `anonymous` Administrator actor,
so API calls do not need an `Authorization` header.

```bash
curl --request GET \
  --url 'http://localhost:18080/api/v1/monitors'
```

<SecurityNote>
Anonymous access is intentionally unrestricted. Anyone who can reach Rhythm can
view and change resources, run monitors, and perform Administrator actions.
Restrict network reachability outside the application if that exposure is not
acceptable.
</SecurityNote>

Webhook receiver tokens, integration credentials, secret references, and
downstream service authentication remain independent of user access. Continue
to store those values in the configuration library or approved secret store.

## Playground behavior

The documentation playground can call the configured Rhythm API origin without
a bearer token. Its safety controls for destructive operations and webhook
receivers remain separate from application authentication.
