Variable resolution follows local → request/run → environment → monitor → global precedence. Script-created values persist only for the current run.

Secrets are referenced by alias and resolved at execution time. JavaScript can read an approved alias with `pm.vault.get`, but cannot create, update, or delete secrets.

<CaptureState state="MASKED">The value influenced execution but is intentionally unavailable.</CaptureState>
<CaptureState state="POLICY_BLOCKED">Capture policy prohibited storing the value.</CaptureState>
<CaptureState state="NOT_CAPTURED">The value was not recorded for this execution.</CaptureState>

<SecurityNote>Never duplicate a secret into a normal environment variable to make it visible. Diagnostics, copy actions, events, exports, and accessibility text enforce the same masking policy.</SecurityNote>
