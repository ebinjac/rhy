## Prerequisites

Install Docker Desktop with enough memory for PostgreSQL, MinIO, the API, and the browser agent. Redis is optional because PostgreSQL is the default queue transport.

<Procedure>
1. Clone the Rhythm repository.
2. From the repository root, run `docker compose up --build`.
3. Wait for the health checks to become healthy.
4. Open Rhythm at `http://localhost:3100`.
5. Configure ELF against an available OpenSearch endpoint when log checks are needed.
</Procedure>

```bash
docker compose ps
curl --fail http://localhost:18080/healthz
```

<ExpectedResult>The API reports `ok` and the web interface loads without Redis.</ExpectedResult>

<FailureExample>If the API is not ready, inspect the migration and PostgreSQL health before rebuilding application containers.</FailureExample>
