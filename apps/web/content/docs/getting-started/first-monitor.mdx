<Procedure>
1. Open **Monitors → New monitor**.
2. Name the monitor and link its application and service.
3. Add an HTTP request with a method and allowed URL.
4. Add an assertion for the expected status.
5. Choose **Try request** to validate the unsaved definition.
6. Create the monitor, open Builder, and publish the draft.
7. Choose **Run now**.
</Procedure>

<ExpectedResult>The manual run moves from queued to a terminal state and exposes safe step, attempt, network, extraction, and assertion evidence.</ExpectedResult>
