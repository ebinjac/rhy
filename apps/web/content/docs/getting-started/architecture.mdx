Rhythm separates authoring and policy from execution. The API persists immutable revisions and queues work. Workers execute monitors, while isolated agents provide governed access to target networks. PostgreSQL stores durable state and Redis coordinates asynchronous work.

The JavaScript runner receives bounded, masked input and creates a fresh VM for every script. ELF searches use the configured OpenSearch connection and store only sanitized, bounded evidence.

## Request path

`Web → API → queue → worker or agent → target API → masked diagnostics`

## Log-validation path

`Web → API → ELF proxy → OpenSearch → sanitized evidence → gate decision`

<SecurityNote>Workers and agents enforce DNS re-resolution, SSRF, proxy, TLS, timeout, cancellation, and capture policy at execution time.</SecurityNote>
