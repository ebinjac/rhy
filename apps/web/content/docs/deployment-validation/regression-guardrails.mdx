A performance regression requires both:

1. Post-deployment p95 is at least 25% slower than baseline p95.
2. Post-deployment p95 is at least 100 ms slower.

The comparison runs at aggregate-monitor and required HTTP-step level using API-only timing. Any failed active sample from a required monitor blocks. Optional failures and regressions warn. Blocking ELF failures block; advisory ELF failures warn.
